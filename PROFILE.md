# Tadeus API

Tadeus is an AI voice agent platform that interviews your workforce in real voice, acts on what it hears, and returns structured records into existing systems. The public Integration API lets you create interview templates and campaigns, invite participants, and retrieve transcripts, structured results, and AI insights programmatically.

- **Tadeus Integration API** — REST API to create interview templates and campaigns, invite participants, and retrieve transcripts, structured results, and AI insights. API-key auth via X-API-KEY-ID and X-API-SECRET headers. (`https://app.tadeus.net/api/integration/v1`)
